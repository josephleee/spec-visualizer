# Borrowbox

Borrowbox is the lending desk of a neighbourhood tool library: members sign up, find a drill or a ladder in the catalog, borrow it at the counter and bring it back on time.

This folder is the example project that `spec-visualizer --demo` shows. It is written with [spec-kit](https://github.com/github/spec-kit): one constitution and seven features, each at a different stage, so every page of the dashboard has something to draw. The product is made up; no code belongs to it.
