# Proposal: Add tool search

## Why

Members ring the library to ask whether a tool is in. Volunteers walk to the shelf to look. A search page answers the question before anyone walks anywhere.

## What Changes

- A search box on the catalog page, for members and volunteers alike.
- Each result says whether the tool is on the shelf or lent, and until when.

## Capabilities

### Modified Capabilities
- `tool-catalog`: adds searching by name and category.

## Impact

- Catalog page and its query; a word index rebuilt when an entry changes.
