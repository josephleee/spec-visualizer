# Proposal: Add a waitlist

## Why

The two tile cutters are lent out every weekend. Members ask to be told when one is back.

## What Changes

- A member can join the waitlist of a tool that is lent.
- When the tool comes back, the first member on the list has it held for one day.

## Capabilities

### New Capabilities
- `waitlist`: queueing for a lent tool and holding it on return.

## Impact

- Catalog result rows; the return flow at the counter.
