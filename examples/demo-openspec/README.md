# Borrowbox

Borrowbox is the lending desk of a neighbourhood tool library: members sign up, find a drill or a ladder in the catalog, borrow it at the counter and bring it back on time.

This folder is the OpenSpec example that `spec-visualizer --demo --format openspec` shows: three capability specs, two archived changes and five changes in progress, one at each stage. The product is made up; no code belongs to it.
