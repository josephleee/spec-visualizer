# Borrowbox

Borrowbox is the lending desk of a neighbourhood tool library: members sign up, find a drill or a ladder in the catalog, borrow it at the counter and bring it back on time.

This folder is the Kiro example that `spec-visualizer --demo --format kiro` shows: four steering files and six specs, one of them a bugfix, spread over every stage. The product is made up; no code belongs to it.
